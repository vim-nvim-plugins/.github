## vim-nvim-plugins

Small, dependency-light plugins for Vim and Neovim. Each one works with vim-plug, native packages or a bare `runtimepath+=`.

| Plugin | What it does |
|---|---|
| [sigil](https://github.com/vim-nvim-plugins/sigil) | Lists every variable in the current file in a side panel — jump, cycle, filter, rename. Tree-sitter, 21 languages. |
| [vibe](https://github.com/vim-nvim-plugins/vibe) | AI coding assistant — chat about code with local or hosted models. Vim 8.2 and Neovim. |

Issues and pull requests go to each plugin's own repo.
